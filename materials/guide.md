# Teacher Guide

## How to run a session

1. Log in as **teacher** or **super**.
2. Open **Teaching** and pick a test, difficulty, and count.
3. Use **Peek Answer** / **Show Explanation** on the same page while discussing.
4. Students stay in **Test** mode — they cannot peek.

## How to add content

- Add a JSON file to `/questions/` and list it in `/questions/index.json`.
- Add a file to `/materials/` and list it in `/data/materials.json`.
- Push to GitHub. No database, no POST.
