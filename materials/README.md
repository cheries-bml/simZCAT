# Materials

Add files here: .pdf, .png, .jpg, .txt, .md

Then add an entry to `data/materials.json`:

```json
{ "id": "m3", "title": "My Handout", "file": "materials/my-handout.pdf", "type": "pdf", "description": "..." }
```

Commit and push. GitHub Pages will serve the new file. No POST requests are used.
