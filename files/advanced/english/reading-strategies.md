# Reading strategies

Use these steps on every passage.

1. **Skim** the title and first sentence of each paragraph.
2. **Read the questions** before the passage.
3. **Mark** words that signal contrast: *however*, *although*, *yet*.
4. **Infer** from clues instead of guessing.

## Inference checklist

- What does the author say directly?
- What is only suggested?
- Which answer is supported by the text, not by your opinion?

```
Main idea = what the whole passage is about
Detail    = one fact that supports it
```
