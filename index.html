      How to update data

      1. In GitHub, edit data/users.json, data/roles.json, data/config.json, questions/*.json or data/materials.json  •  2. Commit & push  •  3. GitHub Pages redeploys automatically. To add a question file, upload it to questions/ and add it to config.json → questionsFiles.

      infoTo add a user: add an entry to users.json with a SHA-256 hash of the password. Generate it with: echo -n "newpassword" | shasum -a 256
